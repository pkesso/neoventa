# Neoventa — Venta Overdrive PCB

A PCB for the Venta Overdrive, a clone of the PE-12 overdrive by Elektronika. The board is 50 × 54 mm, has 2 layers and fits a Hammond 1590N1 (125B) enclosure. SMD parts go on the bottom side and are assembled by JLCPCB. Pots, the LED and the wire pads go on the top side and are soldered by hand.

The schematic and the board are generated by Python scripts from a single circuit description (`tools/circuit2.py`). The layout was not drawn by hand in KiCad.

## Hardware

- **Enclosure:** Hammond 1590N1 (66.5 × 122 × 39.5 mm).
- **Knobs:** 2 × 2. Volume and Drive on top, Eq and Resonance below. IN/OUT jacks on the sides, power on the top.
- **Pots:** Alpha 16 mm, right-angle PCB mount, B50k. Eq is a dual-gang pot.
- **Op-amps:** 4558 (JRC4558D, LCSC C443686).
- **Footswitch:** 3PDT, wired to the board. The status LED is a 5 mm red LED on the board.
- **Wire pads:** J1 IN, J2 OUT, J3 +9V, J4/J5 GND, J6 LED− (to the 3PDT).

### Changes from the original circuit
- 1N5817 → SS14, 47 µF → 22 µF ceramic, 1.5 MΩ → 1 MΩ (input pull-down).
- Added 3 × 100 nF supply decoupling caps for the op-amps, and the LED with a 3.3 kΩ resistor (~2 mA).
- 1.5 nF filter caps are C0G (NP0).

## Simulation

The schematic contains SPICE fields (`Sim.*`) that point to `simulations/venta.lib`. The library has behavioural models of the op-amp, the diodes and the pots. To run a simulation in KiCad, open Inspect → Simulator. The analysis is taken from the `.tran` text on the schematic. Pot positions are set in the `Sim.Params` field of RV1..RV4 (`POS = 0..1`). V1/V2 are simulation-only sources.

The plots in `simulations/` are generated by `simulate.py`:

```bash
.venv/Scripts/python simulations/simulate.py
```

It builds the netlist from `tools/circuit2.py` and runs ngspice as a shared library: by default the `ngspice.dll` that ships with KiCad 10 (`C:\Program Files\KiCad\10.0\bin`). Set `NGSPICE_DLL` to use a different one.

- `sim_frequency.png` — small-signal frequency response for the Eq and Resonance knobs at 0/50/100 %.
- `sim_waveforms.png` — 440 Hz, 100 mV input and the output at Drive 10/50/100 %.

## Tools

Python 3 with numpy, scipy and matplotlib:

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
```

`tools/verify2.py` also needs the standalone [ngspice](https://ngspice.sourceforge.io) program. It runs ngspice as a separate program, so it can't use KiCad's `ngspice.dll` the way `simulations/simulate.py` does.

Scripts are run from the `tools/` directory. The pipeline:

| Step | Script | Input → output |
|---|---|---|
| Circuit | `circuit2.py` | Single source of truth: parts, nets, footprints, board side, LCSC numbers |
| Initial placement | `render.py` | → `placed.json`, `placement.png` |
| Placement optimisation | `anneal.py` | `placed.json` → `placed2.json` |
| Routing | `run_route.py` (uses `route.py`) | `placed2.json` → `routed.pkl`, `routed.png` |
| DRC | `drc.py` | `routed.pkl` → report |
| Schematic | `gen_sch2.py` | → `.kicad_sch`, `.kicad_pro`, `Venta.kicad_sym`, `sym-lib-table`, `symuuid.json` |
| Board | `write_pcb.py` | `routed.pkl`, `symuuid.json` → `.kicad_pcb`, `Venta.pretty/`, `fp-lib-table` |
| Check | `verify2.py <file.kicad_sch>` | Rebuilds connectivity from the schematic, compares it with `circuit2.py`, runs ngspice |
| Drilling template | `drill_template.py` | Hole positions from `place.py` → `../drill_template_1590N1.pdf` (A4, 1:1) |

Helper modules: `place.py` (board outline, placement), `route.py` (2-layer grid router, 0.25 mm grid), `pcb_core.py` (footprint loading and geometry, reads `tools/fplib/`), `k10fmt.py` (KiCad 10 library format).

Notes:
- `routed.pkl` is in `.gitignore`. Without it, `write_pcb.py` can only run after routing again.
- `gen_sch2.py` and `write_pcb.py` overwrite the KiCad files. Changes made by hand in KiCad will be lost if you regenerate them.
